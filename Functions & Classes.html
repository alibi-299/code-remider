Functions & Classes

    return

    Exits a function and optionally passes back a specified value.

    lambda

    Used to create short, anonymous (nameless) functions inline.

    class

    Used to define a class in Python

    yield

    Pauses a function and returns a generator value to the caller.

    global

    Used to declare a variable as global, allowing it to be accessed and modified from within a function.
