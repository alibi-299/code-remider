Forms & Interactive Elements




  • form

    • Orchestrates collection areas for user input components.

  • input

    • Accepts typed, toggled, or chosen user criteria values.

  • textarea

    • Ardizes expansive multiline text entry zones.

  • button

    • Activates generic click behaviors or form submissions.

  • select

    • Generates scrolling or compact option dropdowns.

  • option

    • Configures item components nested inside selection nodes.

  • optgroup

    • Labels related item listings inside options matrices.

  • label

    • Links textual contexts to interactive input tags.

  • fieldset

    • Isolates grouped interactive items inside border containers.

  • legend

    • Titles structured parent fieldset frames.

  • datalist

    • Attaches autocomplete selection options to inputs.

  • output

    • Tracks calculations generated by dynamic input actions.

  • progress

    • Measures operational progress via graphical progress bars.

  • meter

    • Gauges scalar values resting inside specified ranges.

  • details

    • Generates disclosure toggles readers can expand.

  • summary

    • Generates the label for expanding details boxes.

  • dialog

    • Generates overlay components like popup dialog boxes.
