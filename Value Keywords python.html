Value Keywords




  • True

    • The Boolean true value

  • False

    • The Boolean false value

  • None

    • Represents a null value or the absence of a value

  • Control Flow & Loops

    • control flow refers to the order in which the program's code executes

  • if

    • Used to create a conditional statement

  • elif

    • Used to specify an additional condition to be checked if the previous if or elif condition is false

  • else

  • Used to specify a block of code to be executed if the condition in the if statement is false

  • for

    • Used to create a loop that iterates over a sequence.

  • while

    • Used to create a loop that continues to execute as long as a specified condition is true

  • break

    • Used to exit a loop prematurely

  • continue

    • Used to skip the current iteration of a loop and move next one

  • pass

    • Used as a placeholder for code that is not yet implemented or to create an empty block of code
