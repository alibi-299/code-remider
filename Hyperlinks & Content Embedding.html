Hyperlinks & Content Embedding




  • a

    • Sets up hyperlinks using target URL properties.

  • img

    • Places external graphic files inside layout zones.

  • iframe

    • Embeds separate webpage frames within current documents.

  • embed

    • Generates execution wrappers for outside plugin platforms

  • object

    • Houses multifaceted internal/external interactive item entities.

  • picture

    • Offers resource flexibility for dynamic image generation.

  • source

    • Lists alternative media assets for video or audio engines.

  • video

    • Embeds playback modules for local or streamable video.

  • audio

    • Embeds playback modules for local or streamable audio.

  • track

    • Connects timed text caption resources to media modules.

  • map

    • Generates clickable spatial image coordinates maps.

  • area

    • Configures interactive coordinates inside maps.
