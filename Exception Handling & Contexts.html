Exception Handling & Contexts


    try

    Used to define a block of code to be tested for exceptions.

    except

    Used to define a block of code to be executed if an exception of a specific type occurs.

    finally

    Used to define a block of code that will be executed regardless of whether an exception occurred.

    raise

    Used to raise an exception manually.

    with

    Used to wrap the execution of a block of code within methods defined by a context manager.

    assert

    Used to test if a condition is true. If the condition is false, an AssertionError is raised.
