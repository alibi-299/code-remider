page semantics




  • header

    • Represents introductory content or a site-wide navigation bar.

  • nav

    • Groups structural sets of navigation hyperlinks.

  • main

    • Isolates the singular, dominant content block of the page document.

  • section

    • Groups standalone, generically relevant blocks of thematic content.

  • article

    • Encloses self-contained compositions intended to be independently re-distributable.

  • aside

    • Marks off-topic text blocks or sidebars contextually tied to surrounding parts.

  • footer

    • Demarcates trailing data blocks like copyright text or contact elements.

  • address

    • Contains semantic contact markup details for people or physical organizations.

  • h1

    • Defines the highest level main document heading.

  • h2

    • Defines secondary standard section subheadings.

  • h3

    • Formats third-level subheadings embedded inside content fields.

  • h4

    • h2>

    Defines minor fourth-level document section headers.

  • h5

    • Generates deep fifth-level editorial item headings.

  • h6

    • Represents the deepest, smallest native semantic heading tier.

  • hgroup

    • Groups a heading element with accompanying subheadings.
