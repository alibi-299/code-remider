# HTML Personal Dashboard & Notes

This project is a small collection of static HTML, CSS, and JavaScript files for a personal browser-based dashboard, notes app, and study/reference pages.

## Included pages

- `start page.html` — landing page / entry point
- `dashboard personal.html` — personal dashboard layout
- `notes.html` + `script.js` — note-taking interface
- `password-html.html` + `password.js` — password-related page
- `new Arsenal.html` and related files — sample content / UI experiments
- `code remider/` — HTML and Python reference notes

## Features

- Simple static website structure
- Personal dashboard styling
- Notes app with add-note interaction
- CSS-based layout experiments and demo pages
- No framework or build setup required

## Run locally

Because this is a static site, you can open any HTML file directly in a browser.

For example:

```bash
cd "C:\Users\inese\Desktop\html"
python -m http.server 8000
```

Then open:

```text
http://localhost:8000/start page.html
```

You can also use VS Code's Live Server extension for quick local preview.

## Notes

This project is mainly a frontend learning/demo workspace, so it is intentionally lightweight and does not include a package manager or build pipeline.
