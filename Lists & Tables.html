Lists & Tables




  • ul

    • Generates bulleted unordered list containers.

  • ol

    • Generates numbered ordered list containers.

  • li

    • Represents list items nested inside ul/ol blocks.

  • dl

    • Configures glossary description list frameworks.

  • dt

    • Identifies subject terms inside description trees.

  • dd

    • Stores explanatory definitions for description terms.

  • table

    • Implements structured rows-and-columns data matrices.

  • caption

    • Titles parent table structures with headers.

  • thead

    • Groups structural header content inside table blocks.

  • tbody

    • Groups primary data row elements inside tables.

  • tfoot

    • Groups summarized footer components inside tables.

  • tr

    • Declares single, horizontal row spaces inside tables.

  • th

    • Formats specific cells as bolder table column headers.

  • td

    • Fills layout tables with foundational data cells.

  • colgroup

    • Manages layout property bundles across table columns.

  • col

    • Targets matching attributes inside column groups.
