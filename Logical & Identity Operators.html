Logical & Identity Operators


    and

    Used to combine multiple conditions in a conditional statement

    or

    A logical operator that returns true if at least one expression is true.

    not

    A logical operator used to invert a Boolean value.

    in

    Used to check if a value is present in a sequence (like a list or string).

    is

    A logical operator that returns true if both variables refer to the same object.
