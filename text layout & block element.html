text layout & block element




  • p

    • Organizes running text into paragraphs.

  • div

    • Acts as a generic block-level element container used for structural layout layout manipulation.

  • span

    • Functions as a generic inline container used to style small text snippets.

  • br

    • Executes an instantaneous single-line break within layout bodies.

  • hr

    • Renders a thematic visual partition line separating content fields.

  • pre

    • Handles layout-sensitive preformatted content by maintaining code blocks, spaces, and indents.

  • blockquote

    • Indents an extended section quoted from an external source.

  • wbr

    • Indicates a safe word-break point for lengthy strings
